SECURITY MODEL

No inbound public listener

  • Pairing key: one use, 10-minute TTL.
  • Agent credential: random token; database stores SHA-256 only.
  • Commands: allowlisted structured actions, never shell commands.
  • Proxy toggle controls registry state only; it does not stop the proxy process itself.
  • Remote proxy use: prefer a private overlay such as Tailscale.
